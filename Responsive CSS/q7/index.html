Responsive Design

Responsive web design allows a webpage to adjust its layout according to the device and screen size. It uses flexible layouts, images and media queries.

CSS Cheat Sheet

Grid: Creates rows and columns.

Flexbox: Aligns items in a layout.

Media Queries: Adjust styles for different screens.
